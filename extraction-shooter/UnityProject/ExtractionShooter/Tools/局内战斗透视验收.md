## 复测

1. Unity 保持 MCP 已连接；在项目目录执行 `powershell -ExecutionPolicy Bypass -File Tools/Run-CameraAcceptance-Live.ps1`。三个测试组均显示全部通过才算自动验收通过。
2. 手动流程：Unity 菜单 `Tools > 料理地牢 > 镜头系统 > 一键开始逐步体验验收`。点面板“下一步”（或 N/F9）；依次体验小镇、餐厅、选关、地牢、返回。
3. 地牢中静止/移动分别把鼠标从中心移到边缘：中心不偏移，边缘不无限漂移，静止/移动上限一致；指向 UI 时回中。
4. 向不同方向瞄准、开火并绕过怪物：弹体方向与瞄准一致，怪物可受伤；精灵不躺平、转向不改变碰撞体。
5. 检查近/远处相同尺寸物体的大小关系，再返回小镇：近大远小，返回后恢复小镇跟随，无地牢镜头残留。
6. 单独弹体验证：打开 Layer1 并 Play，执行 `Tools > Modules > Test Combat Projectile (Play)`，报告须为 PASS。脚本创建临时靶，发射后清理，不扣弹药、不生成奖励。
