# 镜头逐步体验验收

## 启动

1. 打开 Unity 工程。
2. 按 `Ctrl+Shift+M`，确认 MCP 显示已连接。
3. 双击 `Tools/Start-Camera-Guided-Acceptance.cmd`。
4. 切到 Unity 的 Game 窗口。出现“料理地牢镜头逐步验收”面板即启动成功。

也可以直接使用 Unity 菜单：`Tools > 料理地牢 > 镜头系统 > 一键开始逐步体验验收`。

运行中：`N` 或 `F9` 下一步并定位，也可以点击面板底部按钮；`F8` 隐藏/显示面板，`F10` 从头开始。

启动后先确认正式小镇已显示，玩家出生在策划指定建筑旁。满足后按第一次 `N`/`F9`，或点击面板底部的“下一步”。

## 第 1 步：小镇跟随与朝向前瞻

操作：使用 WASD 朝一个方向移动约 2 秒并停下，再朝相反方向移动。

通过标准：

- 镜头开始跟随时没有瞬移或明显抖动。
- 玩家停下后镜头平滑停稳。
- 改变移动朝向后，镜头平滑把更多可视空间留在玩家朝向一侧。

## 第 2 步：餐厅

按 `F9` 后会定位到餐厅入口。按 `E` 进入，尝试 WASD，按住鼠标中键拖动画面，最后按 `Esc` 离开。

通过标准：

- 玩家进入后固定在餐厅座位，WASD 不能移动角色。
- 镜头稳定在餐厅中心。
- 当前餐厅为透视镜头，中键拖拽半径不超过 1.5；鼠标在 UI 上不拖动。
- 离开后玩家回到餐厅入口，移动恢复。

## 第 3 步：地图选关

按 `F9` 后会定位到地面传送点。按 `E` 打开地图，点击已解锁的 `Layer1`。进入地牢后再按 `F9`。

通过标准：

- E 能正常打开地图和区域选择。
- Layer1 正常加载，没有黑屏、双相机或旧镜头残留。
- 转场过程中没有丢失主相机。

## 第 4 步：地牢镜头

先保持玩家静止，把鼠标放在画面中心，再缓慢移动到半程和边缘；随后把鼠标放到 UI 上；最后把鼠标保持在边缘并用 WASD 移动。

通过标准：

- Layer1 / Layer2 / Layer3 为透视俯视镜头；相同尺寸物体近处更大、远处更小。
- 角色、怪物等非地面视觉保持正对镜头，不会像贴在地板上一样躺倒；其物理根节点不受视觉朝向影响。
- 鼠标在中心死区时镜头基本不偏移。
- 鼠标离中心越远，镜头偏移越大，边缘处不会无限移动。
- 玩家静止或移动时都使用同一个 3 米偏移上限，移动过程中不会累计漂移。
- 鼠标悬停 UI 时镜头回到玩家中心。
- 玩家移动时镜头仍是平滑跟随，不会首帧瞬移。

## 第 5 步：地牢返回

按 `F9` 后会定位到地牢出口。按 `E` 返回小镇，返回完成后再按 `F9`。

通过标准：

- Layer1 正常卸载，恢复为 Town 镜头。
- 地面玩家仍在进入地牢前的传送点附近。
- 玩家移动恢复。
- 没有地牢镜头请求残留。

## 判定

面板中的“自动观测”用于确认事件确实发生，不替代主观画面判断。五步均达到对应标准才算手工体验验收通过。
